# teum. — AI SDK 실험 r1~r15

**정리일: 2026-10-24.** 같은 자사 코드 표본으로 조사와 독립 검증을 실행한 r1~r15의 수치와 변경 내용을 정리했습니다.<br>
첫 4/4 성공본 r5와 최종 두 회차 r14/r15의 평균을 비교하면 **API 요청 92.6%·총토큰 88.0%·시간 32.2%·usage 추정 비용 32.7% 감소**를 관측했습니다.<br>
r14와 r15는 각각 핵심 조건 **4/4**, 세부 조건 **16/16**을 충족했습니다.<br><br>

이 기록은 현재 서비스의 AI 경로와 별도로 실행한 개발용 SDK 실험입니다.<br>
같은 모델의 읽기·출력·검증 방식을 바꿨으며 반복해서 본 고정 표본의 결과를 일반 정확도로 환산하지 않았습니다.<br><br>

이 문서의 ‘최종 두 회차’는 **r1~r15 구간의 r14/r15**를 가리킵니다.<br>
같은 날 이어진 r16/r17은 품질 조건을 충족했지만 더 느려 채택하지 않았고, r18은 출력 상한으로 최종 보고서를 완성하지 못했습니다.<br>
후속 후보를 기각한 뒤 r14/r15의 생성 방식을 유지했으며, 아래 15회 합계에는 r16~r18을 포함하지 않습니다.<br><br>

원문 인용의 일치와 설명의 의미 검토도 별도로 확인했습니다.<br><br>

### 어떤 변경을 남겼나요?

파일 ID와 인용 좌표를 줄여도 서버가 원래 파일·줄·역할로 되돌리고 실제 전달한 원문과 대조하는 검사는 유지했습니다.<br><br>

r14/r15에서는 각 단계의 독립 reader가 읽은 원문을 첫 요청에 제공했습니다.<br>
조사와 검증은 여전히 별도 문맥이며 요청을 줄였다고 두 검토를 하나로 합치지는 않았습니다.<br>
모델의 파일 읽기 왕복은 줄이되 원문·전체 검증 설명·정확 인용을 남기는 데 중점을 뒀습니다.<br><br>

## 05. 요청을 줄여도 시간이 계속 줄지는 않았습니다

직전 성공본 r11/r12 평균과 비교하면 다른 결과가 보입니다.<br><br>

| 지표 | r11/r12 평균 | r14/r15 평균 | 변화 |
|---|---:|---:|---:|
| API 요청 | 15회 | 2회 | 86.7% 감소 |
| 합계 토큰 | 745,925.5 | 208,733 | 72.0% 감소 |
| 출력 토큰 | 59,173.5 | 63,200.5 | 6.8% 증가 |
| 전체 시간 | 17:18.610 | 18:13.274 | 5.3% 증가 |
| usage 추정 비용 | $1.0012 | $0.9958 | 0.5% 감소 |

입력 전달에서는 중복이 크게 줄었지만 출력은 늘었고 전체 시간도 더 걸렸습니다.<br>
전체 15회 중 가장 짧게 4/4를 충족한 회차는 **r12의 15:44.953**입니다.<br>
최종 선택은 요청·입력 토큰 절감을 우선한 결과이며 모든 지표에서 가장 빠른 설정이라고 부르지 않았습니다.<br><br>

같은 코드로 두 번 실행해도 시간이 달랐습니다.<br>
서로 다른 회차의 차이를 변경 한 가지의 순수 효과로 분리하거나, 두 번의 평균을 일반 저장소의 성능 보장으로 확대하지 않았습니다.<br><br>

## 06. 확인한 범위와 남은 검증

| 확인한 것 | 범위 |
|---|---|
| 실행 결과 | 최종 보고서 생성 11회·실행 실패 4회, 완료 보고서 중 핵심 4/4는 8회 |
| 원문·조건 보존 | 고정 표본, 같은 평가 기준, 정확 인용과 미확인 범위 대조 |
| 무료 재생 | 실제 SDK와 가짜 제공자로 읽기·큰 응답·중단·usage 보존·최종 조립 확인 |
| 실제 품질 | 해당 회차의 최종 설명을 개발자가 원문·평가 기준과 직접 대조 |

무료 재생은 전송과 조립 경로를 검사합니다.<br>
실제 모델의 의미 이해나 생성 시간을 새로 측정한 결과로 사용하지 않습니다.<br>
고정한 자사 표본을 반복해서 보며 수정했으므로 독립 고객 저장소나 맹검 평가의 결과로 일반화할 수 없습니다.<br>
핵심 4/4를 충족해도 입력 밖 코드, 실제 배포·권한 철회·경합 등의 미확인 내용은 남습니다.<br><br>

SDK 실험 결과를 현재 서비스 엔진에 연결하는 작업과 큰 저장소·운영 Linux/Sandbox 검증은 이 기록의 완료 범위에 포함하지 않았습니다.<br>
공개판에는 수치와 구현 선택을 정리했으며 코드 원문·모델 원 응답·키·계정 정보는 싣지 않았습니다.<br>
이 문서를 작성하며 추가 유료 모델 호출은 하지 않았습니다.<br>
