# 화면으로 보는 teum.

[README로 돌아가기](../README.md) · [샘플 체험 열기 ↗](https://teum.today/demo)

로그인이나 저장소 연결 없이 검토 흐름을 볼 수 있습니다.<br>
샘플은 설명용 코드와 결과로 구성되며 실제 분석을 실행하지 않습니다.<br>
처리 상태를 바꾸면 해당 브라우저에만 반영됩니다.<br><br>

## 01. 규칙 분석의 근거를 읽습니다

[결제 서비스의 규칙 분석 결과](https://teum.today/demo/scans/R-042?source=rules)를 엽니다.<br>
발견 목록에서 항목을 선택하고 위치·위험 설명·코드 근거를 확인합니다.<br>
처리 상태는 사람이 남기는 검토 기록이며, 스캐너가 관측한 결과와 별개입니다.<br><br>

![샘플 규칙 결과의 목록과 상세](../assets/screenshots/rule-review.jpg)

<br>
<br>

## 02. AI 후보의 성립 조건을 살펴봅니다

[AI 검토 결과](https://teum.today/demo/scans/R-042?source=ai)에서 ‘다른 사용자의 계정이 조회될 수 있어요’를 선택합니다.<br>
먼저 확인할 일, 처리 지점의 근거, 입력 지점과 보호 조건을 차례로 읽습니다.<br>
아래로 내려가면 발견 시점 코드와 수정 제안을 비교할 수 있습니다.<br>
수정안은 직접 검토할 예시이며 자동 적용되지 않습니다.<br><br>

![샘플 AI 후보와 먼저 확인할 일](../assets/screenshots/ai-review.jpg)

<br>
<br>

## 03. 결과와 점검 범위를 함께 봅니다

[부분 완료 사례의 점검 범위](https://teum.today/demo/scans/R-047/coverage)를 엽니다.<br>
완료한 단계와 확인하지 못한 범위를 구분해 보세요.<br>
발견 목록만 보고 전체 점검이 끝났다고 오해하지 않도록 만든 화면입니다.<br><br>

![부분 완료 샘플의 점검 범위](../assets/screenshots/coverage.jpg)

<br>
<br>

## 04. 기록과 리포트로 이어갑니다

[주문 서비스의 점검 기록](https://teum.today/demo/projects/rules)에서 이전 점검과 재점검을 살펴볼 수 있습니다.<br>
[리포트](https://teum.today/demo/scans/R-042/report)에서는 결과와 범위, 실행 기록을 함께 읽을 수 있습니다.<br><br>

실제 서비스에서는 GitHub의 새 커밋으로 재점검합니다.<br>
샘플의 사례 선택·초기화는 체험을 위한 기능이며 실제 분석 결과를 선택하는 기능이 아닙니다.<br>
